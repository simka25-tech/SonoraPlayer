# Sonora — плеер для Synology Audio Station

Android-приложение (Kotlin + Jetpack Compose + Media3), которое подключается к Audio Station на вашем Synology NAS.

## Возможности

- Вход по адресу NAS (HTTP/HTTPS), поддержка двухфакторной аутентификации и самоподписанных сертификатов
- Демо-режим без NAS (свободные треки SoundHelix)
- Библиотека: песни (с подгрузкой при прокрутке), альбомы, исполнители, избранное
- Поиск по песням, альбомам и исполнителям
- Фоновое воспроизведение, уведомление и управление с экрана блокировки
- Очередь: «воспроизвести далее», «добавить в очередь», удаление, переход к треку
- Таймер сна с плавным затуханием или «до конца трека»
- Скорость воспроизведения 0.5×–2×
- Перекодирование в MP3 на стороне NAS (экономия трафика, любые форматы)
- История и «Чаще всего» на главной, карточка «Мне повезёт»
- Интерфейс перекрашивается под цвет обложки текущего трека

## Анимации

Плывущий «аврора»-фон, пружинящие нажатия, эквалайзер у играющего трека, обложка «дышит» при паузе
и листается свайпом, кнопка play/pause меняет форму, сердечко «подпрыгивает», параллакс в альбомах,
мерцающие заглушки при загрузке, плавные переходы между экранами, мини-плеер со свайпами.

## Сборка

Нужны JDK 17 и Android SDK (проще всего — Android Studio).

1. Откройте папку `SonoraPlayer` в Android Studio и дождитесь синхронизации Gradle.
2. Run ▶ на телефоне или эмуляторе, либо **Build → Build APK(s)**.

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
